# 🐙 Splitopus Bot

**Splitopus** — это Telegram-бот для удобного учета совместных расходов в путешествиях и компаниях. 
Больше не нужно спорить, кто за что платил и кто кому сколько должен. Бот сделает всё сам!

## ✨ Возможности

*   **⚡️ Быстрый ввод:** Просто напишите `500 Обед` в чат.
*   **👥 Семейные счета (Партнеры):** Объединяйте балансы с партнером (траты одного считаются тратами семьи).
*   **📊 Прозрачный баланс:** В любой момент видно, кто в плюсе, а кто в минусе.
*   **💸 Умный расчет долгов:** Бот подскажет, кто кому и сколько должен перевести, чтобы закрыть все долги минимальным количеством транзакций.
*   **🎲 Рулетка:** Не можете решить, кто платит за ужин? Рулетка выберет счастливчика (это считается угощением!).
*   **📝 Заметки:** Храните коды от замков, пароли Wi-Fi и важную информацию прямо в поездке.
*   **📂 Экспорт:** Выгрузка всех трат в CSV (Excel).

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/dennysandreev/splitopus-bot.git
cd splitopus-bot
```

### 2. Настройка
Создайте файл `.env` в корневой папке и добавьте туда токен вашего бота (получить у @BotFather):

```env
BOT_TOKEN=ваш_токен_здесь
```

### 3. Запуск
Бот написан на Python (требуется версия 3.8+). Внешние зависимости минимизированы (`requests`).

```bash
# (Опционально) Создайте виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install requests

# Запуск
python3 bot.py
```

## 🛠 Структура проекта

*   `bot.py` — Точка входа, обработка команд и сообщений.
*   `src/`
    *   `telegram.py` — Обертка над Telegram API (с защитой от Rate Limits).
    *   `data.py` — Работа с данными (JSON файлы).
    *   `logic.py` — Финансовая логика и математика расчетов.
*   `data/` — Здесь хранятся базы данных пользователей и поездок (не попадают в Git).
